hushhconnect

A private messenger that never asks for your phone number or email.

The problem

Most chat apps start with a phone number or an email address. That makes people easy to find, scrape and spam — and it ties a conversation to an identity you may not want to share.

How it solves it

You pick a name, a unique Chat ID and a password. People find you by that ID, not a contact list. Messages move in realtime. A hashed Recovery ID plus a security answer gets you back in if you forget the password — the Chat ID alone never can. Text only: no feed, no media noise.

Built with

  • React
  • Supabase Realtime
  • hCaptcha
  • Vercel
