I started building because a college attendance sheet annoyed me enough to make something better. That habit stuck.

I’ve spent the last few years learning by building, breaking things, and figuring out why they broke. Along the way, I’ve worked on real-time applications, web platforms, data-driven systems, and projects involving AI and machine learning.

I use Java and C++ for algorithms and problem solving, JavaScript for the web, and Python for data and machine learning. Currently, I’m looking for opportunities to work on real software, learn from experienced engineers, and become better at building things that people actually use.
