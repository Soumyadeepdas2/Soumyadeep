BookyUniverse

A digital library you can search, save and read without leaving the page.

The problem

Ebooks usually live in scattered files, folders and tabs. Finding a title, remembering where you stopped, and actually reading it means jumping between apps. A growing shelf gets harder to use, not easier.

How it solves it

One shelf. Search by title or author, filter by subject, save a personal collection, and open the book in the same page. The catalogue lives in Supabase so the library can grow without rebuilding the front end.

Built with

  • JavaScript
  • Supabase
  • Vercel
