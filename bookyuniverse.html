BookyUniverse

A digital library you can search, save and read without leaving the page.

Project details

Type
Digital library with in-page reader
Role
Design, build, catalogue schema
Catalogue
24 ebooks · 9 collections

BookyUniverse is a single-page digital library. A vanilla JavaScript front end holds the catalogue, renders the searchable grid, and opens any book in an in-page PDF.js reader — search by title or author, filter by collection, save a personal shelf. Book PDFs and covers are hosted on Supabase Storage; saved books, theme and last-read stay in localStorage. No accounts, no backend.

Built with

  • JavaScript
  • Supabase
  • Vercel

The problem, in structure

  1. Shelves are scattered. Ebooks live as files in folders, attachments in chats, tabs half-open.
    • one book, three apps
    • nothing remembers where you stopped
  2. Finding means remembering. Without search, a title is a memory exercise, not a lookup.
  3. Reading needs a detour. Opening a book means leaving the page you found it on.
  4. Saving needs another tool. A personal collection usually means a separate app or account.
  5. Growth makes it worse. A folder-based shelf gets harder to use as it grows.

How it answers each one

  1. One shelf. Every title lives on the same page — files, folders and tabs collapse into a single library.
  2. Search as you think. Find by title or author, filter by subject — lookup, not memory.
  3. Open in place. The book opens inside the same page; reading never leaves the library.
  4. Save as you browse. The personal collection is built into the shelf itself.
  5. Catalogue, not folders. The library lives in Supabase, so growth is rows, not rebuilds.
