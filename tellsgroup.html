Project 05 · 2026

Tellsgroup

Eighteen media brands, one parent system, no eighteen stylesheets.

Project details

Type
Multi-brand media network hub
Role
Design, build
Interactions
Search · filters · counters · chatbot

Tellsgroup is a static front-end for a media network — one page holding the parent company and every Tells desk. Plain HTML, CSS and JavaScript on Vercel: hamburger navigation with a scroll indicator, brand search and category filters, scroll-driven goal cards, an animated statistics counter and a scripted cat chatbot. No database, no API, no CMS — every interaction runs in the browser.

Built with

  • HTML
  • CSS
  • JavaScript
  • Vercel

The problem, in structure

  1. Brand-by-brand becomes site-by-site. A growing network turns into a pile of disconnected homes.
    • different layouts per brand
    • readers must learn eighteen homes
  2. Eighteen stylesheets. Brands rebuilt alone mean duplicated style work and quiet drift.
  3. No shared search. A story on one desk is invisible from every other.
  4. The parent disappears. No single place shows the whole group at once.
  5. Every launch is a clone. A new vertical starts by copying an entire site.

How it answers each one

  1. One page, one group. The parent company and every Tells desk share a single home.
  2. One system, many voices. Each brand keeps its own topic and tone on a shared frame — no eighteen stylesheets.
  3. One search, shared filters. News, sports, lifestyle and knowledge sit behind the same controls.
  4. The group stays visible. Shared identity lets readers see the whole network at once.
  5. Plug in, don’t clone. New verticals launch inside the system, not as copies of it.

Architecture

Next phase

  • Per-brand article pages on the same frame.
  • Cross-desk search results grouped by brand.
  • Desk and author pages for deeper reading.
  • Per-desk archives so older stories stay reachable.
